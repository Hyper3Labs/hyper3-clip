# Hyper3-CLIP: Hierarchy-Conditioned Hyperbolic Vision-Language Training

Hyper3-CLIP is a hierarchy-conditioned hyperbolic vision-language model that combines query-conditioned visual pooling with hyperbolic entailment objectives; query-conditioned pooling is active only during training, so at inference the model is a standard dual encoder and adds no extra computation.
