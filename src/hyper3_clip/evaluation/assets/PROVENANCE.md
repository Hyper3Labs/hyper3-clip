# Evaluation assets — provenance

Every file in this directory is vendored verbatim from a public upstream
release so that the evaluation protocol of the paper can be reproduced without
re-deriving label orders or hierarchy graphs.  Nothing here is generated by
this repository, and nothing here is modified.

| file | upstream origin | contents |
|---|---|---|
| `class_names_hycoclip.py` | official **HyCoCLIP** release, `hycoclip/evaluation/class_names.py` | `CLASS_NAMES: dict[str, list[str]]` with keys `aircraft, caltech101, cars, cifar10, cifar100, clevr, country211, cub2011, dtd, eurosat, flowers102, food101, imagenet, mnist, openimages, pcam, pets, resisc45, sst2, stl10, sun397`.  Class counts: food101=101, cifar10=10, cifar100=100, cub2011=200, sun397=397, cars=196, aircraft=100, dtd=47, pets=37, caltech101=102, flowers102=102, stl10=10, eurosat=10, resisc45=45, country211=211, imagenet=1000.  Every `class_names_key` used by `configs/eval/paper_table_3.yaml` resolves against this file. |
| `all_synsets.pkl` | official HyCoCLIP release, `assets/imagenet_synset/all_synsets.pkl` | Pickled `list[str]` of 1000 WordNet synset ids giving the **official ImageNet label ordering** that the hierarchy metrics index into. |
| `all_ancestors_indices.pkl` | official HyCoCLIP release, `assets/imagenet_synset/all_ancestors_indices.pkl` | Pickled `list[list[int]]`, one ancestor-index list per official label.  Drives Jaccard, LCA, hierarchical precision and hierarchical recall. |
| `imagenet_isa.txt` | official HyCoCLIP release, `assets/imagenet_synset/imagenet_isa.txt` | 1371 lines of space-separated `parent child` WordNet is-a edges.  Read as an undirected graph for the tree-induced-error shortest paths.  Byte-identical (md5 `f5f06133cddf4983f8f875de5cb7a366`) across the HyCoCLIP, UNCHA and PhyCLIP releases — the three baselines share one hierarchy asset. |

The class-name module carries its upstream copyright header; it is loaded by
file path with `importlib` (see `hyper3_clip.evaluation.class_names`) and is
never imported as part of this package's public API.

The pickles are trusted, read-only data files shipped inside the wheel.  They
contain only lists of strings and lists of integers.
